# Changelog

## 1.0.0

First Windows release.

- Sign in through GP Cloud's own web login in a private window. The app never handles your password.
- Browse My Drive in a grid (with thumbnails) or a list. Recent, Starred, Trash, and search.
- Upload files and whole folders by drag-and-drop or the New menu, using the multipart protocol with retries, parallel slices and instant (dedup) uploads.
- Download with progress, open files in their default app, show downloads in Explorer.
- New folder, rename, move, copy, star, Trash (restore, delete forever, empty).
- System tray icon: open the app, upload to My Drive, storage tooltip. Closing the window keeps GP Cloud running in the tray.
- Keyboard: Delete, F2, Enter, Ctrl+A, Ctrl+F, F5, Alt+↑, Ctrl+Shift+N, Ctrl+U.
- Installer (setup.exe) or MSI, Windows 10/11 x64.
